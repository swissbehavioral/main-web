# Open questions

| Question | Why it matters | Needed from |
|---|---|---|
| VPS self-hosting or Appwrite Cloud? | Operational ownership and deployment | Project owner |
| Which VPS, OS, capacity and existing proxy? | Installation topology, ports and resource sizing | Infrastructure owner |
| Which website/Appwrite domains? | DNS, TLS and runtime endpoint | Domain owner |
| Which Appwrite server version/project? | SDK/schema/scope compatibility | Backend operator |
| Who may access the dashboard? | Authorization and revocation design | Admissions/project owner |
| What sensitive data may be collected and retained? | Form fields, storage, access and deletion | Responsible client reviewers |
| Do existing leads need migration? | Avoid records being stranded in old provider | Current operator |
| Are notifications, CRM or staffed chat required? | Integration scope and provider choice | Project owner |
| Where is the existing personal/team Obsidian vault? | This folder is standalone; no external vault has been connected | User, if external placement is desired |
| Who owns backups, alerts and recovery? | Production support continuity | Project owner |

These are tracked inputs for future work, not reasons to stop independent source/documentation work.
