# Glossary

| Term | Meaning in this project |
|---|---|
| Appwrite SDK | npm client library used by website server code |
| Appwrite instance | Running backend service, self-hosted or Cloud |
| Appwrite project | Logical resource boundary inside an instance |
| Bootstrap | Script creating database schema and optional user in an existing project |
| Provider | Appwrite or JSON implementation behind the lead facade |
| SSR | Website pages rendered through a Node server |
| Lead | Inquiry, insurance request or chat submission |
| Chat widget | Form-like message capture, not staffed live messaging |
| Health probe | Read/connectivity check, not complete acceptance testing |
| Context vault | This organized Markdown knowledge folder, usable in Obsidian |
| Live verified | Tested against the actual named environment, with date and evidence |
